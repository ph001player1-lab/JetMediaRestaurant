# Файлы для Windows

Двойной клик — откроется командная строка и всё сделает сама (PowerShell не нужен):

- `server-connect.cmd` — подключиться к серверу (SSH);
- `server-deploy-test.cmd` — выкатить на тест (test.jetmedia.dev);
- `server-deploy-release.cmd` — выкатить на рабочую (app.jetmedia.dev), сначала спросит подтверждение.

Подготовка планшетов по USB — в папке `provisioning` (`provision.cmd`, `check.cmd`).
