# Пакет ИИ-персонажа

Персонаж — один JSON-файл. Его загружает администратор в портале (вкладка «ИИ-персонажи») и там же отмечает, каким ресторанам персонаж доступен: остальные его не видят. Менеджер ресторана выбирает разрешённого персонажа в своём кабинете (вкладка «ИИ-персонаж») и может заменить фразы из пакета своими: сколько угодно вариантов приветствий, рекомендаций и фраз про блюдо дня — у каждого ресторана свои. Пример — [`characters/mia.json`](../characters/mia.json).

## Поля

| Поле | Что это |
|---|---|
| `id` | Короткий латинский идентификатор, например `mia`. Повторная загрузка с тем же `id` заменяет персонажа |
| `name` | Имя на языках гостя: `{ "en": "Mia", "ru": "Мия", "th": "…", "zh": "…" }` |
| `images.idle` | Картинка «молчит» (рот закрыт) |
| `images.talk` | Картинка «говорит» (рот открыт). Пока персонаж говорит, картинки чередуются |
| `phrases.recommend`, `phrases.dayDish` | Необязательно: варианты фраз-рекомендаций по умолчанию (массив `{ ru, en, th, zh }`), `{dish}` — место названия блюда. Без `{dish}` название блюда звучит в конце фразы. Персонаж берёт случайный вариант; цену не произносит — она на карточке. Ресторан может заменить их своими в ЛК |
| `voice.pitch`, `voice.rate` | Высота и скорость голоса синтезатора речи (1 — обычные) |
| `greetings` | Варианты приветствия по умолчанию: массив `{ ru, en, th, zh }` (старое поле `greeting` — одно приветствие — тоже понимается). Ресторан может заменить их своими в ЛК |
| `dialog.start` | С какого узла начинается разговор |
| `dialog.nodes` | Узлы сценария: `{ "say": {…}, "buttons": [{ "label": {…}, "go": "…" }] }` |

Картинки — PNG, JPEG, WebP или SVG: встроенные в файл как `data:image/...;base64,…` или ссылкой. Встроенные картинки сервер сохраняет отдельными файлами при загрузке пакета. Размер пакета — до 25 МБ. Картинка лучше вертикальная, с прозрачным фоном, высотой 800–1200 px.

## Куда ведут кнопки (`go`)

| Значение | Что происходит |
|---|---|
| имя узла | Персонаж говорит реплику этого узла и показывает его кнопки |
| `recommend` | Совет из меню ресторана: блюдо дня, акционное или любое блюдо с фото |
| `dish:<id>` | Открыть меню на категории этого блюда |
| `menu` | Открыть меню |
| `waiter` | Вызвать официанта (на планшете у входа кнопка скрывается) |

## Голос

Если в портале подключён ElevenLabs и персонажу выбран голос, каждую фразу озвучивает сервер: первый раз синтезирует, сохраняет MP3 и дальше отдаёт готовый файл. Изменили фразу — при следующем показе она озвучится заново. Без ElevenLabs или без интернета персонаж молчит — гость видит только текст.

В любой фразе можно ставить теги ElevenLabs в квадратных скобках — эмоции (`[playful]`, `[excited]`), звуки голоса (`[giggles]`, `[laughing]`, `[sighing]`), подачу (`[whispering]`, `[pause]`) и звуковые эффекты (`[applause]`, `[bell ringing]`). Их понимает модель `eleven_v3`; с другими моделями сервер их убирает. На экране гость тегов не видит.

## Свободный разговор

Сейчас персонаж ведёт разговор по сценарию из пакета и подбирает блюда из меню ресторана. Свободные ответы через языковую модель подключим, когда на сервере появится API-ключ: сценарий останется запасным вариантом без интернета.

## Права на персонажей

Узнаваемые мультипликационные персонажи (например, Маша из «Маши и Медведя») защищены авторским правом. Использовать их образ и голос в ресторане можно только по лицензии правообладателя. В пакеты для ресторанов кладём либо собственных персонажей, либо материалы, на которые у ресторана есть лицензия.
