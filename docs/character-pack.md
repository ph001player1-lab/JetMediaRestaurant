# Пакет ИИ-персонажа

Персонаж — один JSON-файл. Его загружает администратор в портале (вкладка «Персонажи»), а менеджер ресторана выбирает персонажа в своём кабинете (вкладка «ИИ-персонаж»). Пример — [`characters/mia.json`](../characters/mia.json).

## Поля

| Поле | Что это |
|---|---|
| `id` | Короткий латинский идентификатор, например `mia`. Повторная загрузка с тем же `id` заменяет персонажа |
| `name` | Имя на языках гостя: `{ "en": "Mia", "ru": "Мия", "th": "…", "zh": "…" }` |
| `images.idle` | Картинка «молчит» (рот закрыт) |
| `images.talk` | Картинка «говорит» (рот открыт). Пока персонаж говорит, картинки чередуются |
| `audio.greeting` | Необязательно: записанное приветствие (MP3) по языкам `{ ru, en, th, zh }`, как `data:audio/mpeg;base64,…`. Играет вместо синтеза и показывает текст из `greeting` на том же языке, поэтому запись должна совпадать с текстом. Языки без записи и все остальные фразы — синтез речи, как раньше |
| `voice.pitch`, `voice.rate` | Высота и скорость голоса синтезатора речи (1 — обычные) |
| `greeting` | Приветствие на языках гостя |
| `dialog.start` | С какого узла начинается разговор |
| `dialog.nodes` | Узлы сценария: `{ "say": {…}, "buttons": [{ "label": {…}, "go": "…" }] }` |

Картинки — PNG, JPEG, WebP или SVG: встроенные в файл как `data:image/...;base64,…` или ссылкой. Встроенные картинки сервер сохраняет отдельными файлами при загрузке пакета. Размер пакета — до 25 МБ. Картинка лучше вертикальная, с прозрачным фоном, высотой 800–1200 px.

## Куда ведут кнопки (`go`)

| Значение | Что происходит |
|---|---|
| имя узла | Персонаж говорит реплику этого узла и показывает его кнопки |
| `recommend` | Совет из меню ресторана: блюдо дня, акционное или любое блюдо с фото |
| `dish:<id>` | Открыть меню на категории этого блюда |
| `menu` | Открыть меню |
| `waiter` | Вызвать официанта (на планшете у входа кнопка скрывается) |

## Голос

Персонаж говорит через встроенный в планшет синтезатор речи Android (агент 0.1.6 и новее). Голос пока стандартный: русский, английский, тайский или китайский — в зависимости от выбранного гостем языка. Узнаваемый голос персонажа (записанные фразы или облачный синтез с подобранным голосом) — следующий шаг.

## Свободный разговор

Сейчас персонаж ведёт разговор по сценарию из пакета и подбирает блюда из меню ресторана. Свободные ответы через языковую модель подключим, когда на сервере появится API-ключ: сценарий останется запасным вариантом без интернета.

## Права на персонажей

Узнаваемые мультипликационные персонажи (например, Маша из «Маши и Медведя») защищены авторским правом. Использовать их образ и голос в ресторане можно только по лицензии правообладателя. В пакеты для ресторанов кладём либо собственных персонажей, либо материалы, на которые у ресторана есть лицензия.
