# Подготовка планшетов по USB

## Один раз на каждом планшете

1. Сброс к заводским настройкам. При первой настройке **не входить в Google-аккаунт** (пропустить).
2. Настройки → О планшете → 7 раз нажать «Номер сборки» → появятся «Параметры разработчика».
3. Параметры разработчика → включить «Отладка по USB».
4. Подключить к компьютеру. На планшете появится запрос — поставить «Всегда разрешать» и нажать «Разрешить».

## На компьютере (Windows)

1. Скачать архив: https://github.com/ph001player1-lab/JetMediaRestaurant/archive/refs/heads/claude/brave-ride-0arxnd.zip и распаковать, например в `C:\JetMedia`.
2. Открыть папку `provisioning` внутри распакованной папки.
3. Двойной клик по `check.cmd` — только проверка, ничего не меняет.
4. Двойной клик по `provision.cmd` — настройка. ADB и свежий агент скрипт скачает сам.
   Скрипт спросит ключ регистрации (показан в конце установки сервера; его запомнит файл `device-key.txt`) и Wi-Fi ресторана.
   Ключ можно пропустить — тогда планшет нужно добавить в портале: «Устройства» → «Новые устройства». Перед работой проверьте строку
   «Версия скрипта» в начале окна: если её нет, папка старая — скачайте архив заново.

Варианты запуска из PowerShell в этой папке:

```powershell
.\provision.cmd -CheckOnly                       # только проверить, ничего не менять
.\provision.cmd -Watch                           # подключаете планшеты по одному, каждый настраивается сам
.\provision.cmd -WifiSsid "Rest" -WifiPass "123" # заодно подключить Wi-Fi
.\provision.cmd -StartUrl "https://jetmedia.dev" -Pin "4321"  # какую страницу показывать и PIN сервиса
```

Результаты пишутся в `provision-log.csv`.

## Сервисное меню на планшете

7 быстрых касаний в левом верхнем углу → PIN (по умолчанию `1234`). Там: открыть настройки, перезагрузить страницу, **снять владельца устройства** — планшет вернётся в обычный режим без сброса.

## Если «НЕ ГОТОВ»

- **Есть аккаунт** или **несколько пользователей** — сброс к заводским, без входа в Google.
- **Уже есть владелец устройства** (например, FreeKiosk) — снять его в настройках того приложения или сбросить планшет.
