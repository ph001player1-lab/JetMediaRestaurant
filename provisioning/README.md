# Подготовка планшетов по USB

## Один раз на каждом планшете

1. Сброс к заводским настройкам. При первой настройке **не входить в Google-аккаунт** (пропустить).
2. Настройки → О планшете → 7 раз нажать «Номер сборки» → появятся «Параметры разработчика».
3. Параметры разработчика → включить «Отладка по USB».
4. Подключить к компьютеру. На планшете появится запрос — поставить «Всегда разрешать» и нажать «Разрешить».

## На компьютере (Windows)

PowerShell не нужен: только командная строка, ADB и `curl` (он есть в Windows 10/11).

1. Скачать архив: https://github.com/ph001player1-lab/JetMediaRestaurant/archive/refs/heads/claude/brave-ride-0arxnd.zip и распаковать, например в `C:\JetMedia`.
   Или обновить файлы в уже распакованной папке `provisioning`: в адресной строке проводника набрать `cmd`, Enter, и вставить
   `curl -fsSL -O <ссылка на provision.cmd> -O <на check.cmd> -O <на tablet.sh>` (raw-ссылки на эти файлы в ветке).
2. Двойной клик по `check.cmd` — только проверка, ничего не меняет.
3. Двойной клик по `provision.cmd` — настройка. ADB и свежий агент скрипт скачает сам.
   Ключ регистрации спросит один раз и запомнит в `device-key.txt` (админка → «Администраторы» → «Ключ регистрации планшетов»).
   Wi-Fi и PIN сервисного меню берутся из админки сами («Устройства» → «📶 Wi-Fi для всех планшетов»): планшет подключится
   к основной (или первой) сети, остальные агент сохранит сам.
4. Готов один планшет — подключите следующий и нажмите любую клавишу в окне. Закончили — закройте окно.

В начале окна — «Версия скрипта»: если её нет, папка старая — скачайте файлы заново.
Как устроено: `provision.cmd` берёт настройки с сервера (`/api/device/provision-env`), копирует на планшет `tablet.sh`,
агент и настройки в `/data/local/tmp/jm` и запускает `tablet.sh` на самом планшете; потом эту папку удаляет.
`provision.ps1` — прежний вариант для PowerShell, если он у вас работает.

Результаты пишутся в `provision-log.csv`.

## Сервисное меню на планшете

7 быстрых касаний в самом левом верхнем углу (маленький квадрат у края, левее кнопки стола) → PIN (по умолчанию `1234`). Там: открыть настройки, перезагрузить страницу, **снять владельца устройства** — планшет вернётся в обычный режим без сброса.

## Если окно пустое или «ничего не происходит»

Сначала строка `JET MEDIA: starting PowerShell...`, затем `Версия скрипта` и шаги («Запускаю ADB...», «Скачиваю агент...»,
«читаю данные планшета...»). Первый запуск PowerShell после обновления Windows бывает долгим — подождите минуту.
Если ADB завис (осталась копия от другой программы), скрипт через 20 секунд сам закроет все adb и запустит заново.
Остановилось на каком-то шаге — пришлите снимок окна.

## Если «НЕ ГОТОВ»

- **Есть аккаунт** или **несколько пользователей** — сброс к заводским, без входа в Google.
- **Уже есть владелец устройства** (например, FreeKiosk) — скрипт сам пробует снять его через ADB и удаляет FreeKiosk. Если не вышло: в FreeKiosk 5 раз нажать секретную кнопку → PIN → «Remove Device Owner» (не «Exit Kiosk Mode») и запустить скрипт снова; крайний случай — сброс к заводским.
